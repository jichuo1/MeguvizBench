# 修复统计窗口的区间覆盖计算

补全 `solution.py`。程序从标准输入读取一个 JSON 对象，从标准输出返回一个 JSON 整数。对象包含 `window: [start, end]` 和 `ranges: [[start, end], ...]`。所有端点为整数，每个区间满足 `start <= end`。

返回 `ranges` 的并集在 `window` 内覆盖的长度。所有区间都采用左闭右开语义。窗口外的部分不计分，重叠部分只计一次，空窗口和空区间的长度为 0。输入区间可能无序、重复或包含负数端点。测试包含大量重复区间；不要逐整数枚举。

公开示例 `{"window":[0,8],"ranges":[[5,12],[-2,3],[2,4]]}` 返回 `7`。

允许使用 Python 标准库和 shell。交付单个 `solution.py`，不访问网络或写入持久化状态。每次执行从干净目录读取一个请求。
