# 提交环形开关覆盖证书

环有 14 个点，编号为 `0..13`。打开一个开关会覆盖其位置及两个环上相邻点。相邻的开关互斥，其中 `13` 与 `0` 也相邻。最多打开 5 个开关，必须打开 `11`，禁止打开 `1、4、6、9、12`。

必须覆盖这些目标点 `0、1、3、4、5、6、7、9、10、11、12、13`。允许额外覆盖其他点。

提交 UTF-8 JSON 文件 `certificate.json`，仅包含以下两项。

- `selected` 是选中位置的整数数组。
- `witness` 是对象，键为每个目标点的十进制字符串，值为覆盖该点的某个已选开关。每个目标都要给出一个见证。例如若选中 `0`，可用 `"13": 0` 说明跨边界的覆盖。

允许使用 shell、Python 标准库或手工构造。验收只判断该固定实例上构造及证书的合法性。
