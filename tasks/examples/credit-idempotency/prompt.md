# 修复额度扣减的幂等回执

修复 `solution.py`。从标准输入读取 `{"balances":{"account":10},"requests":[...]}`。每项请求包含 `account`、`key` 和 `amount`。按输入顺序处理请求并返回 `{"balances":{...},"responses":[...]}`。

1. 账户不存在时返回 `{"status":"unknown_account"}`。金额必须是正的 JSON 整数，布尔值不算整数，否则返回 `{"status":"invalid_amount"}`。账户和键均为非空字符串。
2. 在同一个账户内，已成功的键使用相同金额重试时，原样返回首次回执 `{"status":"ok","balance":首次扣款后的余额}`。同键换金额则返回 `{"status":"conflict"}`。
3. 新键在余额充足时扣款并保存回执。余额不足时返回 `{"status":"insufficient"}`。失败请求不改变余额，也不占用新键。
4. 不同账户可使用同一个键，互不影响。初始余额为非负整数，当前请求序列的处理相互独立。

公开示例中，账户 `a` 初始余额为 `10`。顺序请求 `a/x/2`、`a/y/1`、`a/x/2` 后，余额为 `7`，三次成功回执的余额依次为 `8`、`7`、`8`。

允许使用 Python 标准库和 shell。交付单个 `solution.py`，不访问网络或写入持久化状态。每次执行从干净目录读取一个请求。
