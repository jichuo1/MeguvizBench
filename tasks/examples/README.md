# 公开平台验证题

六个家族均为合成样例。题面、参考解、错误对照和验收器全部公开，来源记录保留了这一暴露状态。D1、D2 是依据定位和状态复杂度预标的难度，等待试跑校准。

| 家族 | 主维度 | 难度 | 判分重点 | 错误对照 |
| --- | --- | --- | --- | --- |
| `interval-coverage` | 遗留项目维护与架构演进 | D1 | 裁剪、重叠、嵌套、接边、空输入、带符号和大端点 | 嵌套区间使合并边界回退 |
| `sensor-debounce` | 遗留项目维护与架构演进 | D2 | 阈值、重复采样、取消、重新激活、独立传感器和同刻事件 | 重复 true 重置时钟 |
| `credit-idempotency` | 后端与状态一致性 | D2 | 重试回执、冲突隔离、失败恢复和输入校验 | 两个账户共用一份幂等记录 |
| `svg-sync-badge` | 前端与图形 / SVG | D2 | 结构、可访问名称、画布、布局、遮挡和配色对比 | 背景覆盖前景，颜色对比不足 |
| `ring-cover-certificate` | 数学与科学验证 | D2 | 证书结构、环约束、覆盖和逐点见证 | 非法开关使目标缺失，见证不成立 |
| `notched-bracket` | 前端与图形 / 三维 | D2 | OBJ 结构、角点、缺角、面积、闭合边、法向和精确体积 | 缺失一片三角面，网格有开口 |

每份 `task.json` 含 10 至 11 个有固定权重的条目，总分 100。条目分别记录可观察证据、判定方法和失败原因。条目内的多个边界输入共享该条目的固定分值。`caps` 记录关键条目失败时适用的分数上限，多个规则触发时取最低上限。

- 区间任务把裁剪与并集作为核心功能，嵌套回归独立扣分并封顶。大端点用例检查精确输出和可完成性。它没有用于衡量机器速度的分项。
- 告警任务分别计分活动时间阈值、采样保留、去重与重新激活。额度任务把幂等、回执和账户隔离作为核心状态条件。
- SVG 的可见性由受限图形的坐标和绘制顺序判断，配色由相对亮度计算。分项没有比较浏览器截图或字体的实际栅格结果。
- 数学任务直接验证构造的约束与见证。OBJ 验收基于顶点、边和三角形，三维编辑器的视觉检查另行记录。

每个 Python 检查请求都重新执行 `solution.py`，标准输入与标准输出采用 JSON。静态产物由控制侧只读解析。候选目录由运行器为每次试次独立建立，参考解、错误对照和验收器只供控制侧使用。
