# 修复多传感器告警的去抖时序

修复 `solution.py`。程序读取一个 JSON 对象 `{"events":[...]}`，输出告警数组 `[[tick_time, sensor], ...]`。

- `['set', t, sensor, active]` 更新传感器的活动状态，`active` 为布尔值。
- `['tick', t]` 检查当前处于活动状态的传感器。连续活动至少 5 秒的传感器发出告警，每次活动期间最多告警一次。
- 重复的 `true` 不重新计时。一次 `false` 结束活动期，下一次 `true` 重新计时。
- 按输入顺序处理事件。时间为非负整数且不递减，同一时间戳也按输入顺序处理。多个传感器在同一 `tick` 告警时，按传感器名称的字符串顺序输出。

公开示例 `{"events":[["set",0,"a",true],["set",3,"a",true],["tick",5],["tick",6]]}` 返回 `[[5,"a"]]`。

允许使用 Python 标准库和 shell。交付单个 `solution.py`，不访问网络或写入持久化状态。每次执行从干净目录读取一个请求。
