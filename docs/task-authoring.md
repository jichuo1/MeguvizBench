# 任务制作

一个家族对应共同源码、故障根因或构造方法。派生变体保持同一家族 ID。公开样例使用 `synthetic`。私有任务经审阅后使用 `active`，并单独存放在私有材料仓库的 `tasks/`。部署时固定材料仓库的完整 commit SHA。

```text
tasks/<task_id>/
  task.json
  prompt.md
  starter/<声明的起始文件>
  oracle/<参考产物>
  wrong/<关键错误对照>
  checks.py
```

参考 [公开的任务定义](../tasks/examples/interval-coverage/task.json)。使用 `python -m meguvizbench validate --private-tasks PATH` 验证格式。命令会加载任务材料并校验路径、权重、版本、分类、参考文件和错误对照的可读性。评分器代码在受信控制侧执行，因此上传者须由维护者审核。

- 写明期望行为、提交路径、公开样例、允许工具和复位方式。行为任务入口为 `solution.py`，接收一个 stdin JSON 并返回一个 stdout JSON。多模块任务可以声明多个文件。静态文件任务把入口设为 null。任务须声明所需环境能力。
- `checks.py` 提供 `evaluate(artifact, run)`。读取提交目录，或者调用 `run(request)` 从隔离容器拿回 JSON。返回 `{criterion_id: True / False / None}`，覆盖 rubric 全部 ID。对非法格式或候选崩溃，条目应稳定失败。验收期望与比较留在控制侧，勿放到候选可读目录。多次断言归并到预先分配权重的条目。
- Bug 修复分别定义原故障、邻接边界、原有行为和回归面。三维与 SVG 将结构、硬约束、可渲染性、客观布局和视觉判断分开。数学题给出可独立验证的合法性和数值约束，开放研究挑战可记录已知界和候选证书。
- 真实项目在隔离快照中移除账号、凭据、用户数据、参考修复、未来提交和包含答案的 Git 历史。来源项目、固定版本、原故障证据、脱敏过程、曝光风险和任务族依据留私有。用于私有模型试跑的题面与起始文件需要获准发送给选定 API。
- 公开样例已实现 Python 行为任务、SVG、OBJ、JSON 证书。其他环境先实现并验证适配器能力，再启用对应题型。性能任务须固定运行硬件和负载。电脑操作按纯视觉及允许 DOM/ADB/文件接口分别建题集。

## 难度锚点

| 标签 | 定位范围 | 状态与回归 |
| --- | --- | --- |
| D1 | 单点逻辑，给定稳定复现 | 少量邻接边界，无跨模块状态 |
| D2 | 单模块多分支或边界组合 | 已知输入契约，需区分若干回归面 |
| D3 | 两个或更多模块、持久状态或时序耦合 | 需用序列复现，验证故障与恢复 |
| D4 | 跨子系统，异步并发或非稳定故障 | 多种中断、竞态或资源压力，保持外部兼容 |
| D5 | 广泛架构约束与难以复现的生产现象 | 多模块修复取舍，需分层证据、负载与回归矩阵 |

目前标签为作者分级，待用人工解题与独立试跑校准。记录定位跨度、复现稳定性、关键状态交互、回归范围和架构约束。
